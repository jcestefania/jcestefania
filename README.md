## 🌟 Featured Projects

### 🚁 [UAV Search & Rescue (SAR) Optimization Framework](https://github.com/jcestefania/uav-search-and-rescue) *(MSc Thesis 9.6/10)*
> **Autonomous Path Planning for UAVs in Uncertainty Environments using Bio-inspired Metaheuristics & GIS**
- Integrated real GIS geospatial data (OpenStreetMap) with Robert Koester’s **Lost Person Behavior (LPB)** Bayesian probability maps.
- Implemented and evaluated bio-inspired metaheuristic algorithms (**ACO, ABC, BHA, Greedy**) adapted to UAV kinematic constraints and realistic sensor footprint modeling (50 m).
- Validated through hyperparameter tuning with **Optuna** and **900 Monte Carlo simulations** demonstrating superior target probability detection under flight-time restrictions.

### 💺 [Pressure Sensor Seat (IoT Smart Seating)](https://github.com/jcestefania/pressure-sensor-seat) *(BSc Thesis - Distinction / Matrícula de Honor 9.6/10)*
- Designed an end-to-end IoT system with **ESP32** and a custom piezoresistive sensor matrix to analyze ergonomic posture and detect occupancy in real-time.
- Cloud pipeline deployed on **Google Cloud Platform (GCP)** for real-time telemetry, storage, and behavioral classification.

### ⚡ [Parallel Swarm Optimization (PSO)](https://github.com/jcestefania/Parallel-SwarmOptimization-Project)
- Implemented and benchmarked multiple variants of the Particle Swarm Optimization algorithm.
- Explored high-performance parallel execution paradigms using Python multiprocessing, multithreading, and `asyncio` for multi-dimensional optimization spaces.

### 🤖 [NLP Intelligent Assistant](https://github.com/jcestefania/NLP_ChatBot)
- Conversational agent built using Natural Language Processing techniques.
- Features intent classification, Named Entity Recognition (NER), and modular backend logic for conversational context tracking.

### 🧭 [A* Grid Pathfinding Visualizer](https://github.com/jcestefania/Pathfinding-Algorithm-using-A-Star-in-a-2D-Matrix)
- Interactive implementation of the A* algorithm over 2D obstacle matrices.
- Configurable distance metrics (Manhattan vs. Euclidean) with terminal-based trajectory visualization.
